# FinTrack v1.0.0 - Release Notes (draft)

> Draft written for a store listing that never shipped. The project is paused and v1.0.0 has not been released. See the README for what actually works today.

## Planned for v1.0.0
- Track income, expenses, and cash transactions
- Import bank statements (CSV, Excel) from 15 Indian banks; PDF import is experimental
- Transaction categorization: rule-based today, on-device LLM planned for phones with more RAM
- Spending analytics with interactive charts
- Monthly budget tracking with progress rings
- UPI transaction parser
- Biometric & PIN app lock
- Hindi language support (partial)
- Password-protected backup (.fintrack format; not real encryption yet)
- Weekly spending notification summaries (not wired up yet)
- Onboarding flow with account setup
- Dark mode support (coming soon)

## Bank import templates
SBI, HDFC, ICICI, Axis, Kotak, PNB, Bank of Baroda, Canara, Union Bank, IndusInd, IDFC First, Yes Bank, Federal Bank, RBL Bank, AU Small Finance Bank

## Device Requirements (targets, not tested)
- iOS 16.0+ / Android 8.0+
- Minimum 3GB RAM (basic features)
- 4-6GB RAM recommended (AI features)
- ~50MB storage, plus the model download if AI is enabled
